農薬検索ツール — 使い方

FAMIC 公開データと CropLife Japan の RAC コード表を統合したオフライン検索ツールです。 商品名・成分名・RAC コード・作物名・病害虫名から双方向に引けます。

1. 起動方法

ご利用前に毎回「データ更新」を実行することを推奨します。

農薬登録情報は月初に FAMIC で更新されるため、古いデータのままだと新規登録剤や登録変更が反映されません。検索前に データ更新.bat（Windows）または データ更新.command（macOS）を一度ダブルクリックしてください（所要 1〜2 分、ネットワーク接続が必要）。Mac では自動更新も設定できます。詳細は 6. データ更新。

1 まず データ更新.bat（Win）/ データ更新.command（Mac）をダブルクリック
2 完了したら build/これをクリック.html をダブルクリック

既定のブラウザで開きます。約 33 MB、初回読込は 1〜3 秒。起動後はネットワーク接続不要、検索内容は外部に送信されません。

データ更新済みの場合はステップ 2 だけで OK。 同日に再度開く場合は更新不要です。

OS操作
Windowsエクスプローラで build\これをクリック.html をダブルクリック
macOSFinder で build/これをクリック.html をダブルクリック

2. 検索のしかた

上の検索バー: AND 検索

スペースで区切ると すべて満たす剤（AND 条件）に絞り込めます。

アドマイヤー商品名に「アドマイヤー」を含む剤

対象フィールド: 商品名 / 成分名 / 会社名 / 種類名（失効剤）/ 作物名 / 病害虫名 / RAC コード

/ キーで検索ボックスにフォーカスします。

RAC コード検索の系統指定 (Ver. 1.3 から): 数字単独のコード（例: 3）は IRAC/FRAC/HRAC で意味が異なるため、 サイドバーのラジオボタンで検索対象の系統（IRAC / FRAC / HRAC / すべて）を 選べます。検索ボックスに IRAC 4A のように系統を明示入力した場合は、 ラジオボタンの設定より優先されます。

作物群と別名 (Ver. 1.7 から): 「野菜類」「非結球あぶらな科葉菜類」などの作物群で登録された剤は、そこに含まれる作物名でも出ます。 作物の別名・地方名（京菜 → みずな、さつまいも → かんしょ など）でも引けます。 対応表は農林水産省の通知「農薬の適用病害虫の範囲及び使用方法に係る適用農作物等の名称について」の表に 基づくため、表に無い作物は引けないことがあります。使用前には必ずラベルの適用作物名を確認してください。

作物名の一致 (Ver. 1.8 から): 作物名の一部だけが重なる別の作物には当たりません（ちゃ で かぼちゃ、ねぎ で たまねぎ、 なし で くちなし は出ない）。名前の一部での一致は、分類表に載っていない作物名（移植水稲 など）と、 分類表がその作物に含める作物（なし の 日本なし、ぶどう の 大粒種ぶどう など）だけです。 分類表で別の作物とされている ミニトマト・さやいんげん・はつかだいこん などは、その作物名で検索してください。 茶・稲・水稲・小麦・大麦・桑・芝・牧草 などの漢字の作物名は、読み（ちゃ・いね・こむぎ など）でも引けます。

3. サイドバーで絞込

検索バーの絞込に加えて、左サイドバーの条件が すべて AND で働きます。

項目動作
用途殺虫剤 / 殺菌剤 / 除草剤 のチェックボックス。複数可。用途「農薬肥料」の剤は、成分の用途から推定した区分に入り、一覧に「農薬肥料」のバッジが付く
登録状態有効 / 失効 のチェックボックス。どちらも既定で ON
除外「家庭向けを除外」（既定 ON） / 「屋号付き(代理店/OEM品)を除外」（既定 ON。同じ処方で屋号の無い商品が結果にあるときだけ隠す） / 「混合剤のみ」
剤型FAMIC の剤型名（粒剤 / 水和剤 / フロアブル剤 / 液剤 / 乳剤 / ジャンボ剤 / 粉剤 / くん蒸剤 など）から選択。フロアブル剤・ジャンボ剤・ベイト剤は商品名の末尾で分ける
作物入力即時絞込。ひらがな/カタカナ自動変換。作物名の一致は検索バーと同じ規則。798 種の候補
対象病害虫・雑草入力即時絞込。部分一致、1,260 種の候補
適用情報の表示範囲商品の詳細に出る適用表を「指定した作物・病害虫のみ」（既定）か「剤の登録すべて」で表示

詳細の適用表 (Ver. 1.8 から列を追加): 作物名・適用病害虫雑草・希釈倍数・使用量・使用時期・ 本剤の使用回数・使用方法に加えて、適用場所・散布液量・総使用回数（有効成分ごと）・条件（使用目的・適用地帯・ 適用土壌・くん蒸時間・くん蒸温度）を表示します。表示する行のどれにも値が無い列は出ません。 狭い画面では表を横にスクロールしてください。

入力欄のサジェスト: 作物名/病害虫名の欄は頻度順 Top 1,500 までオートコンプリート候補を表示します。

作物/病害虫を入力すると失効剤は自動で隠れます。 失効剤には適用情報（作物・病害虫）が無いためです。失効剤も見るには、これらの欄を空にしてください。

「○○を除く」括弧書きの作物は検索対象外 (Ver. 1.1 から)。 例えば登録上「かんきつ(なつみかんを除く)」とある剤は、サイドバーの「作物」欄に なつみかん と入力してもヒットしません。 「みかん」が登録対象外の剤を、生産者に誤って案内してしまうリスクを防ぐためです。 「かんきつ」と入力すれば従来通りヒットします。

4. RAC バッジの見方

成分名の右隣に、用途分類ごとの RAC コードバッジが付きます (Ver. 1.1 から 3 分類別表示)。

バッジ意味例
IRAC: 4A 殺虫剤 (Insecticide) の作用機作分類 イミダクロプリド (IRAC: 4A ネオニコチノイド系)
FRAC: M7 殺菌剤 (Fungicide) の作用機作分類 ジネブ (FRAC: M3) / シクロブタニル (FRAC: 3)
HRAC: 9 除草剤 (Herbicide) の作用機作分類 グリホサート (HRAC: 9) / グルホシネート (HRAC: 10)
IRAC: UN FRAC: M2 混合剤・殺虫殺菌剤などは複数分類のバッジが並びます 硫黄 (IRAC: UN, FRAC: M2)
対象外 RAC 体系の対象外成分。マウスオーバーで理由表示 脂肪酸エステル (物理作用) / 燐酸第二鉄 (軟体動物剤) / 微生物製剤 / 天敵・植物成長調整剤 (CropLife 表の「-(生)」「-(植)」)
古典未分類 1960–90 年代登録で RAC コード未付与の古典剤 ダイムロン / ACN / DBEDC / ジエノクロル
新規未収録 2025–2026 新規登録で CropLife 表に未収録（次回更新で埋まる見込み） シクロピラニル / シンメチリン / ジンプロピリダズ

現行剤 3,468 件のうち 3,465 件は、全成分が分類済みです。次の 2 成分は未分類（バッジなし）です。

  • アルテリア水和剤の フマル酸: CropLife の表と手動ラベルのどちらにも無い。成分名の一部が重なる別の成分のコードは付けません (Ver. 1.8 から)。
  • エコフィット・ビネガーキラーの 醸造酢: CropLife の表で「-」（RAC の認定なし）だけ。「-」はコードではないので表示しません (Ver. 1.9 から)。

5. エクスポート

検索結果を 4 形式でダウンロードできます。

  • TSV: Excel にそのまま貼り付け可
  • CSV: 文字コード UTF-8 (BOM 付き)。Excel でそのまま開けます (Ver. 1.8 から)
  • Markdown: 報告書・メモ貼り付け用
  • JSON: プログラムから再利用

TSV・CSV・Markdown の列は、登録番号 / 種類名 / 商品名(登録名) / 会社名 / 用途 / 剤型 / 成分 / 混合数 / 登録年月日 / 状態 / 失効年月日 です。 「状態」「失効年月日」は Ver. 1.8 から入れています（失効剤を現行剤と取り違えないため）。 = + - @ で始まるセルは、表計算ソフトで数式として扱われないよう先頭に ' を付けます。 適用表（作物・病害虫ごとの行）は出力しません。

6. データ更新

FAMIC は月初に、CropLife RAC 表は 2〜3 ヶ月ごとに更新されます。

1 Windows: データ更新.bat / macOS: データ更新.command をダブルクリック

1〜2 分で最新データを取得し、これをクリック.html を再ビルドします。

前提詳細
Python 3.8 以上 macOS: 標準搭載（無ければ xcode-select --install）
Windows: python.org か Microsoft Store の "Python 3"。インストール時に "Add Python to PATH" にチェック
ネットワーク接続更新時のみ必要（検索時は不要）
openpyxl初回起動時に自動インストール

Mac で自動更新する (Ver. 1.9 から)

ターミナルで scripts/install_auto_update_mac.sh install を一度実行すると、毎日 12:00 に確認し、前回の成功から 7 日たっていれば自動でデータ更新を行います（Mac が眠っていた分は、起きたときに実行されます）。

コマンド動作
scripts/install_auto_update_mac.sh install登録する
scripts/install_auto_update_mac.sh run今すぐ 1 回実行する
scripts/install_auto_update_mac.sh status登録の状態と直近の結果を表示する
scripts/install_auto_update_mac.sh uninstall登録を外す

結果は ~/Library/Logs/browser-pesticide-search/history.log に残り、失敗したとき・見送ったとき・データが新しくなったときは通知が出ます。

フォルダが外付けドライブにある場合: システム設定 → プライバシーとセキュリティ → フルディスクアクセス に /bin/bash を加えてください。加えないと、自動更新からはドライブを読めず「失敗: SSD のファイルを読めない」と通知されます。加えると、bash で動くほかのスクリプトもディスク全体を読めるようになります。

データ更新後はブラウザのキャッシュを再読み込みしてください。
Windows: Ctrl + F5 / macOS: Cmd + Shift + R

7. よくある質問・トラブル

Q. 作物名で検索したら失効剤が出なくなった

失効剤には適用情報（対象作物・病害虫）のデータが存在しないため、作物/病害虫で絞ると自動的に除外されます。失効剤も見たい場合は、作物/病害虫フィルタを空にしてください。

Q. エンドリン で検索したら「剤型: 乳剤」と出る、化合物名が出ない

剤型欄には FAMIC の剤型名（乳剤 / 粉剤 / 水和剤 / 粒剤 / 液剤 / くん蒸剤 など）を出しています。失効剤は種類名の末尾（エンドリン乳剤 → 乳剤）から剤型を決めます。失効剤には成分の情報が無いため、エンドリン等の化合物名は商品名または種類名の欄で確認してください。

Q. 「トマト」で検索してもミニトマトの剤が出ない

分類表で別の作物とされているためです (Ver. 1.8 から)。ミニトマトの剤は ミニトマト で検索してください。さやいんげん（いんげん）、はつかだいこん（だいこん）、葉たまねぎ（たまねぎ）なども同じです。

Q. RAC コードが付いていない成分がある

RAC 未分類成分は理由バッジを表示します。上記「RAC バッジの見方」を参照してください。アルテリア水和剤の フマル酸 と、エコフィット・ビネガーキラーの 醸造酢 は、どの区分にも入らない未分類で、バッジは出ません。

Q. Windows で開くと文字化けする

HTML 自体は UTF-8 + <meta charset="UTF-8"> 宣言付きなので、どのブラウザでも文字化けしません。ファイル名（「これをクリック.html」「使い方.html」等の日本語名）が化ける場合は、配布時の ZIP 解凍ツールの問題です。対処は配布元に相談してください。

Q. データ更新.bat をダブルクリックすると一瞬でウィンドウが閉じる

Python 3 が入っていません。py -3 --version をコマンドプロンプトで実行して確認し、未インストールなら python.org からインストールしてください。

Q. 検索結果が多すぎる / 少なすぎる

スペース区切りで複数条件を AND で重ねられます。なす アブラムシ イミダクロプリド のように複数指定すると強力に絞り込めます。

農薬登録情報は FAMIC 公開 CSV および CropLife Japan RAC コード表 に基づきます。 データ著作権は各提供元に帰属します。
